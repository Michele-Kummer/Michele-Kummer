# Michele Kummer · SK | SkyOrbit

Turning real-world problems into clear requirements and carefully tested tools.

SK | SkyOrbit is where I build small, dependable tools for everyday digital clutter, starting with photo, video and TV libraries. Each project starts from requirements written as user stories, keeps every change safe to preview before it runs, and is backed by automated tests.

## Projects

### [Media Date Organizer](https://github.com/Michele-Kummer/media-date-organizer)

Gives every photo and video the right date in Windows, and files it by date. A Claude Code plugin and a Python command-line tool.

[Repository](https://github.com/Michele-Kummer/media-date-organizer) · [Project board](https://github.com/users/Michele-Kummer/projects/1) · [Case study](https://github.com/Michele-Kummer/media-date-organizer/blob/main/docs/case-study.md)

[Repository](https://github.com/Michele-Kummer/Plex-Filename-Organizer) · [Project board](https://github.com/users/Michele-Kummer/projects/2)

## How I work

- **Requirements first.** Every feature is a user story with acceptance criteria, grouped into epics, and every bug records its severity, who found it, the steps to reproduce it, and what was expected.
- **Tracked in the open.** Stories and bugs live in GitHub Issues and on the project boards, with priority, severity and the dates they really opened and closed. The original requirements documents show how they were gathered.
- **Safe by default.** The tools preview every change and only make it when asked, never delete a file, and never rename over one.
- **Tested.** Each project has a suite of automated tests that run on generated files, never on real libraries.
- **Documented.** Each project has a README, a contributing guide, a security policy, a code of conduct and an accessibility statement.

**Tools:** Python, PowerShell, Claude Code, GitHub Issues and Projects.
